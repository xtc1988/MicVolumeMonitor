# マイク音量モニター (MicVolumeMonitor)

![.NET](https://img.shields.io/badge/.NET-8.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

リアルタイムでマイク音量を監視し、設定した閾値を超えた際に警告音で通知するWindowsデスクトップアプリケーションです。

## 特徴

- **リアルタイム音量モニタリング**: マイクの音量をdB単位でリアルタイム表示
- **カスタマイズ可能な閾値**: 30dB〜120dBの範囲で警告閾値を設定可能
- **視覚的フィードバック**: 音量メーターバー、警告アラート、色変化による直感的な表示
- **音声警告**: 閾値超過時に緊急性の高いビープ音で通知
- **複数マイク対応**: システムに接続された任意のマイクデバイスを選択可能
- **システムトレイ統合**: バックグラウンドで動作し、必要時のみウィンドウを表示
- **自動起動**: Windows起動時の自動起動設定に対応
- **設定の永続化**: 閾値、警告音量、選択デバイスなどの設定を自動保存

## スクリーンショット

### メイン画面
モダンで直感的なライトテーマのUI設計。Tailwind CSSインスパイアのカラーパレットを採用。

### 主な表示項目
- **現在の音量**: 72ptの大きなフォントで視認性を確保
- **音量メーターバー**: 0〜120dBをビジュアル化
- **閾値マーカー**: 設定した上限をメーター上に表示
- **音量レベル説明**: 設定値が実際にどの程度の音の大きさかを表示
  - 例: 70dB → "掃除機・騒がしい事務所"
- **ピーク値表示**: セッション中の最大音量を記録

## システム要件

- **OS**: Windows 10/11 (64-bit)
- **ランタイム**: .NET 8.0 Runtime
- **オーディオ**: Windows互換の音声入力デバイス

## インストール

### 方法1: リリースパッケージ（推奨）

1. [Releases](../../releases)ページから最新版のZIPファイルをダウンロード
2. ZIPファイルを任意のフォルダに解凍
3. `MicVolumeMonitor.exe`を実行

### 方法2: ソースからビルド

#### 必要な環境
- Visual Studio 2022 または .NET 8.0 SDK
- Windows 10/11

#### ビルド手順

```bash
# リポジトリをクローン
git clone https://github.com/yourusername/MicVolumeMonitor.git
cd MicVolumeMonitor/MicVolumeMonitor

# ビルド
dotnet build -c Release

# 実行
dotnet run
```

または、Visual Studioで`MicVolumeMonitor.sln`を開いてビルド。

## 使い方

### 基本的な使用方法

1. **アプリケーション起動**
   - `MicVolumeMonitor.exe`をダブルクリック

2. **マイク選択**
   - 「マイク選択」ドロップダウンから監視したいマイクを選択

3. **閾値設定**
   - 「音量上限」スライダーで警告閾値を設定（30〜120dB）
   - スライダー下に音量レベルの説明が表示されます
   - 例: 80dB = "地下鉄の車内・ピアノ"

4. **警告音量設定**
   - 「警告音量」スライダーで警告音の大きさを調整（10〜100%）

5. **監視開始**
   - 「開始」ボタンをクリックして監視開始
   - 現在の音量がリアルタイムで表示されます

6. **閾値超過時**
   - 警告アラートが表示される
   - 緊急性の高いビープ音が鳴る（2000Hz/1500Hz交互、2秒間隔）
   - アイコンと音量表示が赤色に変化

### 音量レベルの目安

| dBレンジ | 説明 | 具体例 |
|---------|------|--------|
| 30-40dB | 非常に静か | 深夜の郊外、ささやき声 |
| 40-50dB | 静か | 図書館、静かな住宅 |
| 50-60dB | 普通 | 静かなオフィス、普通の会話 |
| 60-70dB | やや騒がしい | レストラン、電話のベル |
| 70-80dB | 騒がしい | 掃除機、騒がしい事務所 |
| 80-90dB | かなりうるさい | 地下鉄の車内、ピアノ |
| 90-100dB | 非常にうるさい | 犬の鳴き声、工場内 |
| 100-110dB | 危険レベル | 電車のガード下、カラオケ |
| 110-120dB | 聴覚損傷の危険 | 車のクラクション、ロックコンサート |

### システムトレイ機能

- ウィンドウを最小化するとシステムトレイに格納
- トレイアイコンをダブルクリックで再表示
- 右クリックメニューから「開く」「終了」を選択可能

### 自動起動設定

- 「PC起動時に自動起動」チェックボックスをオンにすると、Windowsログイン時に自動的に起動
- 設定はWindowsレジストリに保存されます

## 設定ファイル

アプリケーション設定は以下の場所に保存されます：

```
%APPDATA%\MicVolumeMonitor\settings.json
```

設定内容：
- 閾値 (Threshold)
- 警告音量 (WarningVolume)
- 自動起動 (AutoStart)
- 選択されたマイクデバイス (SelectedDeviceIndex)

## 技術仕様

### 使用技術

- **フレームワーク**: .NET 8.0, WPF (Windows Presentation Foundation)
- **オーディオライブラリ**: NAudio 2.2.1
- **UI設計**: Tailwind CSSインスパイア
- **音量計算**: RMS (Root Mean Square) 方式
- **音声生成**: SignalGenerator (サイン波)

### アーキテクチャ

- **MainWindow.xaml/cs**: UIとイベント処理
- **AudioMonitor.cs**: 音声キャプチャ、音量計算、警告音再生
- **AppSettings.cs**: 設定の読み込み・保存、レジストリ操作
- **IconGenerator.cs**: アプリケーションアイコンの動的生成

詳細は[仕様書.md](./仕様書.md)を参照してください。

## トラブルシューティング

### マイクが検出されない
- Windowsの「サウンド設定」でマイクが有効になっているか確認
- マイクのドライバーが正しくインストールされているか確認
- アプリを管理者権限で実行してみる

### 音量が正しく表示されない
- マイクの入力レベルがWindowsの設定で適切か確認
- 別のマイクデバイスを選択してみる

### 警告音が鳴らない
- Windowsのシステム音量がミュートでないか確認
- 警告音量スライダーが0%になっていないか確認
- オーディオ出力デバイスが正しく設定されているか確認

### 自動起動が動作しない
- アプリケーションの実行ファイルのパスが変更されていないか確認
- Windowsのタスクマネージャー > スタートアップタブで確認
